## Codebase Patterns
- Contract-first: change `openapi/*.yaml`, run the build, then write code. Never edit generated sources.
- A new `*-api.yaml` file is not generated on its own: add its `<execution>` block to the build file too.
- Path order matters: declare `/api/favorites/ids` BEFORE `/api/favorites/{listingId}`, or `ids` is captured as an id.
- A unique compound index annotation does NOT create the index (auto-creation is off by default): check uniqueness in the service.
- JUnit 5 does not run `static` nested classes: put an extra test in its own top-level file, or it is silently skipped.
- Frontend tests: call `fixture.detectChanges()` BEFORE `httpTesting.expectOne()` when `ngOnInit` triggers an HTTP call.
- Before committing, check which git repository you are in: in a multi-repo workspace, a commit at the root does not include the sub-repositories. A previous run lost two iterations on this.
